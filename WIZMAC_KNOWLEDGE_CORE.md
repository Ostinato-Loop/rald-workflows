# WIZMAC Knowledge Core
**admin.rald.cloud/knowledge**
**Phase: 1 — Knowledge Registry**
**Date established: 2026-06-04**

WIZMAC is the institutional memory of RALD.
Every decision, product, service, incident, and plan lives here.
Five years from now, the accumulated knowledge of why decisions were made,
what failed, what succeeded, and how the ecosystem evolved is what turns WIZMAC
into a real operating system for RALD — not just another internal tool.

## 10 Registries

| Registry | Purpose |
|----------|---------|
| Vision | Why RALD exists. Mission, principles, design philosophy. |
| Products | Every product — purpose, owner, status, dependencies. |
| Domains | Every domain — owner, status, health endpoint. |
| Architecture | Service maps, infra, Cloudflare topology, DB decisions. |
| Identity | SSO, sessions, JWT architecture, connected apps. |
| Operations | CI/CD, deployments, service health, uptime. |
| Weekly Planning | P0/P1/P2 priorities. No random development. |
| Incidents | Every production issue — root cause, fix, lessons learned. |
| Regional | Nigeria, Ghana, Kenya, South Africa — launch status, growth. |
| Documentation | API contracts, onboarding, architecture docs. |

## Phase 2 (NOT YET — architecture only)

Future WIZMAC AI learns ONLY from registered documentation.
Never invents ecosystem strategy. Always references the source of truth.
